# Change Record

## v2.0 — Citizen emergency-guidance pivot

All active Markdown documentation was rewritten on 11 September 2026 to reflect the new product direction.

### Execution playbook

`prompt.md` now provides the complete Phase 0–14 implementation prompts, exit gates, verification requirements, execution ledger, and “move to the next phase” protocol. Phases 13–14 remain externally blocked until government authorization and operational evidence exist.

The playbook also enforces inspect-before-asserting, explicit evidence classes, no invented government integrations, no placeholder production code, test-first vertical implementation, dependency verification, diff auditing, and a fixed evidence-based completion report.

### Phase 0–1 execution

Phase 0 established the isolated sthira_v2 boundary, runtime profiles, fail-closed pilot/production guard, legacy warning, and machine-readable inventory. Phase 1 added strict persistence-independent contracts, a synthetic Wayanad operational slice, fixture validation, OpenAPI smoke coverage, and repeatable Makefile checks. The legacy v1 application remains isolated and no live government source is configured.

### Replaced

- Permanent-relocation decision support, land/candidate-site screening, beneficiary allocation, scheme administration, and national clearinghouse scope.
- Sentinel/private/open external data as operational evidence.
- Predictive or software-selected red zones/safe zones/routes.
- Sarvam-branded voice preview and any implication that voice is non-AI.

### Added

- Citizen-facing authoritative alert and guidance flow.
- Government-data-only source policy and a researched official-source register.
- NDMA SACHET CAP as the alert backbone, with IMD/CWC/GSI/INCOIS/FSI/SDMA/DDMA enrichment and operations.
- Pre-approved red zones, safe zones, routes, facilities, capacities, and allocation policy.
- Voice Map Control based on self-hosted AI4Bharat IndicConformer and proposed Indic Parler-TTS.
- Explicit arrival confirmation and concurrency-safe capacity ledger.
- Citizen-confirmed 112/local emergency dialler handoff.
- English/regional language, ISL, non-map, offline, privacy, security, and degraded-mode requirements.
- Future-only boundary for geofence arrival.

### Important implementation status

Documentation is aligned; application code is not. The current codebase remains largely the superseded permanent-relocation prototype. No live government connector, source permission, AI4Bharat model deployment, live safe-zone package, or production emergency integration is claimed.

### Files intentionally not changed

All `.txt` files and non-Markdown source/data files were left untouched by this documentation revision.

## Historical record

Earlier design history remains available in git history. It is not an active requirement source for v2.
