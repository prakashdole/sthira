# Sthira v2 Agent Instructions

Read `GEMINI.md` for the complete standing instructions.

1. Build the citizen emergency-guidance bridge defined by `prd.md`; do not extend the superseded permanent-relocation product.
2. Government systems own alerts, red/safe zones, routes, capacity, allocation, and emergency response. Sthira must not predict them.
3. Follow `rules.md`, `trd.md`, `architecture.md`, and `source-register.md`.
4. Record material decisions in `decisions.md` and unresolved government/policy choices in `open-decisions.md`.
5. Keep live integrations disabled until their source activation gate passes.
6. Do not modify `.txt` files unless the user explicitly changes this instruction.
7. Verify safety-critical behavior, concurrency, degraded modes, accessibility, and the running interface before declaring completion.
